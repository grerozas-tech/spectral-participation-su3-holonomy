## Overview

This repository develops a theoretical operator-geometric mechanism linking heavy spectral participation to an exactly determinant-one, generically full `SU(3)` holonomy.

The central chain is

```text
heavy spectral participation
        -> canonical participation contraction K
        -> weighted cyclic contraction B = K S K
        -> anti-Hermitian oriented contraction
        -> minimal 3+3 defect-plane geometry
        -> exact traceless Wilczek-Zee connection
        -> generic full su(3) holonomy under anisotropy
```

The mathematical claims concern the contraction/defect geometry. Possible applications to quark-family mixing, CKM geometry and determinant-based strong-CP protection are presented as **conditional physical interpretations**, not as experimentally established new physics.

## Main theoretical results

- Canonical heavy participation defines a strict positive contraction `K = [Pi (I+Pi)^(-1)]^(1/2)`.
- A structural cyclic hop compresses to `B = K S K`.
- A generic strict `3 x 3` weighted contraction requires a minimal `3+3` one-step unitary completion.
- For an anti-Hermitian contraction family `C`, the natural defect-plane connection obeys the exact identity `A = 1/2([dC,C] + [D,dD])`, hence `Tr A = 0`.
- The isotropic weighted cycle gives a trivial connection.
- For generic anisotropic weights, the curvature-jet Lie algebra closes to `su(3)`.
- An exact rational certificate gives rank `8` without floating-point tolerance.

## Scientific claim boundary

This repository does **not** claim:

- experimental evidence for new particles or interactions;
- a completed Standard Model flavor derivation;
- a numerical prediction of the CKM matrix;
- a derivation of exactly three particle generations;
- a complete solution of the strong-CP problem.

The core claim is a theoretical construction connecting spectral anisotropy, non-normal weighted contractions, minimal defect geometry and determinant-locked non-Abelian holonomy.
